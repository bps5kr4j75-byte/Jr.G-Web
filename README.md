# Jr.G – Sitio web
Páginas: index, electro-auto, electronica, instalaciones, proyectos, contacto.
- WhatsApp: pon tu número en `js/config.js` (solo dígitos, con lada).
- Fotos: crea carpeta `img/` y cambia cada `<figure class="ph">` por `<figure class="ph"><img src="img/foto.jpg" alt="..."><figcaption>...</figcaption></figure>`.
- Publicar: sube todo a GitHub (el archivo principal es `index.html`); Vercel lo detecta solo.
